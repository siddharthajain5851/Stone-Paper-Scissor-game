 # Stone Paper Scissors Game

This is a browser-based Stone Paper Scissors game built using JavaScript with interactive UI.

## Features
- Button-based user input (Stone, Paper, Scissors)
- Random CPU choice
- Result display (Win / Lose / Draw)
- Live score tracking
- Clean and simple UI

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Play
1. Open index.html
2. Click any option (Stone / Paper / Scissors)
3. View result instantly
4. Score updates automatically
